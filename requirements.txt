# ==============================================================================
# PROJECT SYSTEM & DEVELOPMENT REQUIREMENTS
# ==============================================================================
# Note: This is a .NET C# (Backend) & React TypeScript (Frontend) project. 
# It does not use Python or pip packages.
# ==============================================================================

[Local Development Requirements]
- .NET SDK (v8.0 or later)
- Node.js (v18.x or later) & npm
- SQL Server (Developer/Express edition) or LocalDB, OR Docker (with MSSQL)

[Docker Deployment / Running Requirements]
- Docker Desktop / Docker Engine (v20.10 or later)
- Docker Compose (v2.x or later)

[Key Project Components]
1. Backend: ASP.NET Core API (located in /QM-master)
   - Runs on Port: 7002 (HTTPS) / 8080 (HTTP inside container)
   - Database: Entity Framework Core with SQL Server

2. Frontend: React TypeScript + TailwindCSS (located in /react-risk-system)
   - Runs on Port: 3001
   - API Base URL: https://localhost:7002/api
   - Core Packages (Required):
     * react (^19.2.3)
     * react-dom (^19.2.3)
     * react-router-dom (^7.13.1)
     * recharts (^3.8.1)      <-- For dashboards/analytics charts
     * lucide-react (^0.562.0) <-- For system icons
     * axios (^1.13.2)
     * tailwindcss (^3.4.15)
     * typescript (^4.9.5)

[Quick Start & Installation Commands]
* Note on Red Underlines: If your IDE (like VS Code) shows red lines on 'react', 'lucide-react', or 'recharts', it is because local dependencies are not installed yet. You need to run "npm install" inside the frontend directory.

- To run using Docker:
  docker compose up -d

- To run backend locally (without Docker):
  cd QM-master/WebApplication2
  dotnet run

- To run frontend locally (without Docker):
  cd react-risk-system
  npm install        <-- Installs recharts, lucide-react, react, and all other packages
  npm start
